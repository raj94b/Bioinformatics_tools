<h1>Bioinformatic scripts</h1>

Here are some scripts for various tasks.

In metadata there are scripts used to handle tables (compute group frequencies, adding groups to tables)

In fasta_tools there are scripts used to handle fasta files (compute missing positions, replace gaps etc.)

In genetic_analyses there are scripts used in population genetic analyses, such as iteration of K-means clustering, PCA on haplogroup frequencies etc.)

In modelling there are scripts regarding demographic modeling analyses.
